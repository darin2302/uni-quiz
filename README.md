# Подготовка за изпити

Статичен сайт (GitHub Pages) с четири теста:

- `kgvr/` — Компютърна графика и виртуална реалност
- `tsp/` — Софтуерни технологии
- `okk/` — Основи на компютърните комуникации (изпит: 50 въпроса a–d, 50 мин)
- `oks/` — Основи на компютърните системи (изпит: 25 въпроса a–d × 2 т. + 5 писмени задачи × 10 т., 90 мин)

`*/index.html` се генерират. Не ги редактирай на ръка.

## Обновяване след промяна на въпросите

Въпросите и шаблоните са извън това хранилище: `../kgvr/study/` и `../st/study/` (`L??.md`, `quiz_template.html`, `build_quiz.py`), `../ОКК/study/` и `../ОКС/study/` (`L??.json`, `course.json`, `quiz_template.html`, `build_quiz.py`, `validate.py`; за ОКС и `gen_tasks.py` → `tasks.json`). `publish.py` търси тези папки до сайта или едно ниво по-нагоре и пропуска (оставя публикуваната версия) курс, чиито източници липсват.

ОКК/ОКС: `course.json` задава името, префикса в `localStorage` и формата на изпита. Писмените задачи на ОКС се генерират с `py gen_tasks.py` — отговорите и решенията се изчисляват, не се пишат на ръка. Проверка на въпросите: `py validate.py`.

```
python publish.py
git add -A && git commit -m "Обновени въпроси" && git push
```

`publish.py` пуска `build_quiz.py` и в двете папки, копира `quiz.html` като `kgvr/index.html` и `tsp/index.html` и добавя в `<head>` скрипта `gate.js` и `noindex`. Обновява и броя въпроси в началната страница.

## Смяна на паролата

```
python publish.py --password НОВАТА-ПАРОЛА
git commit -am "Нова парола" && git push
```

В `gate.js` се записва само SHA-256 хешът на паролата. След смяната всеки трябва да въведе новата парола.

## Важно: защитата е само в браузъра

Хранилището е **публично**, а паролата се проверява от JavaScript в браузъра. Всеки, който отвори кода, може да я заобиколи, защото въпросите са в HTML файловете. Паролата само спира случайни посетители. `robots.txt` и `noindex` пазят сайта от търсачките. Не слагай тук нищо, което наистина трябва да е тайно.

## Прогрес

Резултатите, грешните въпроси, историята и името се пазят в `localStorage` на браузъра, с отделни ключове за всеки курс (`kgvr-*`, `tsp-*`, `okk-*`, `oks-*`). За да ги пренесеш на друго устройство, отвори „Моят прогрес“, натисни „Експорт“, копирай кода и го постави с „Импорт“ на другото устройство.

## Локален преглед

```
python -m http.server 8000
```

След това отвори http://127.0.0.1:8000/. Проверката на паролата използва `crypto.subtle`, а то работи само по HTTPS или на localhost.
